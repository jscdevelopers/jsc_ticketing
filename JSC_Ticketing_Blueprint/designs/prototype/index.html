Packaged for JSC Ticketing planning and implementation

This standalone HTML illustrates proposed Angular menus, dashboard lenses, ticket detail, stage hover/focus information, a first-claim action, and a workflow designer.

All sample names, counts, records and dates are fictional. The real Angular application requires the Nite backend and PostgreSQL workflow engine specified in the docs. The samples do not confer any real access or submit data.
